# 🚀 Advanced To-Do List

A modern and interactive To-Do List application built using **HTML, CSS, and JavaScript**.

## ✨ Features

* Add new tasks
* Delete tasks
* Save tasks using Local Storage
* Animated gradient background
* Glassmorphism UI design
* Responsive layout
* Smooth animations and transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Local Storage API

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/pj669193-cyber/advanced-todo-list.git
```

2. Open the project folder

```bash
cd advanced-todo-list
```

3. Open `index.html` in your browser
